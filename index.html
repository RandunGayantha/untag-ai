What gets removed

EXIF

Camera, software, timestamps, GPS location, editing history.

XMP / IPTC

Adobe-style descriptive data, including the DigitalSourceType field some AI tools write.

C2PA / Content Credentials

The signed JUMBF manifest embedded by tools such as DALL·E, Firefly and others.

Generation parameters

PNG text chunks like parameters, prompt, workflow from Stable Diffusion UIs and ComfyUI.

FAQ & honest limits

Will this make an image impossible to detect as AI-generated?

No. It removes embedded metadata only. It does not touch the pixels in lossless mode, so invisible watermarks (e.g. SynthID, Stable Signature) and platform classifiers that analyse the image itself can still flag it. Re-encode mode changes pixels slightly but is also not a guarantee.

Is it okay to remove these tags?

Stripping metadata is a normal privacy step (it also removes GPS data). But many platforms – Instagram, TikTok, YouTube, X and others – require you to disclose realistic AI-generated content yourself, and removing a label does not change that rule. Please follow each platform's policy and local law.

Is anything uploaded?

No. All processing uses JavaScript in your browser. You can disconnect from the internet after loading the page and it keeps working.

Do social networks strip metadata anyway?

Many re-compress uploads and drop some fields, but they may read C2PA/XMP before doing so. Removing it yourself first avoids relying on that.
